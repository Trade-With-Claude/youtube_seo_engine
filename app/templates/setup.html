Setup Guide

One-time setup to connect your YouTube channel. Takes about 5 minutes.

Quick Start

  1. Copy .env.example to .env
  2. Get a YouTube API key (Step 1-3 below) → paste in .env
  3. Run pip install -r requirements.txt
  4. Run uvicorn app.main:app --reload
  5. Go to Dashboard → paste your channel URL

OAuth (Steps 4-5) is optional — only needed for private analytics like search terms, revenue, and traffic sources.

1

Create a Google Cloud Project

  1. Go to Google Cloud Console
  2. Click Select a Project → New Project
  3. Name it something like youtube-seo-engine
  4. Click Create and wait a few seconds
2

Enable YouTube APIs

  1. In your project, go to APIs & Services → Library
  2. Search and enable these 3 APIs:
    • YouTube Data API v3 — public channel/video data
    • YouTube Analytics API — your private channel analytics
    • YouTube Reporting API — bulk reporting (optional)
3

Create an API Key

  1. Go to APIs & Services → Credentials
  2. Click + Create Credentials → API Key
  3. Copy the key and add it to your .env file: 
    YOUTUBE_API_KEY=your_api_key_here
  4. (Optional) Restrict the key to YouTube Data API v3 only for security
4

Set Up OAuth (for Analytics)

  1. Go to APIs & Services → OAuth consent screen
  2. Choose External user type → Create
  3. Fill in:
    • App name: YouTube SEO Engine
    • User support email: your email
    • Developer contact: your email
  4. Scopes: add yt-analytics.readonly and yt-analytics-monetary.readonly
  5. Test users: add your Google email
5

Create OAuth Credentials

  1. Go to Credentials → + Create Credentials → OAuth client ID
  2. Application type: Web application
  3. Authorized redirect URIs: add http://localhost:8000/auth/callback
  4. Click Create, then copy the Client ID and Client Secret
  5. Add them to your .env file: 
    GOOGLE_CLIENT_ID=your_client_id
GOOGLE_CLIENT_SECRET=your_client_secret
GOOGLE_REDIRECT_URI=http://localhost:8000/auth/callback

You're all set!

Restart the app and head to the Dashboard to add your channel.

Note: In testing mode, OAuth is limited to 100 test users. This is fine for personal use.

# Phase 4: Competitors & Scoring — Plan

## Acceptance Criteria

**AC1:** Given a channel is added, when I click "Discover Competitors", then the app searches YouTube for channels in the same niche and shows discovered competitors with stats.

**AC2:** Given I'm on the competitors page, when I paste a channel URL, then that channel is added as a competitor and tracked.

**AC3:** Given keywords exist and a channel has data, when I click "Score Keywords", then each keyword gets a composite score and the table sorts by opportunity.

## Tasks

### Task 1: Competitor discovery + manual add + tracking page
- **files**: `app/services/competitors.py`, `app/routers/competitors.py`, `app/templates/competitors.html`, `app/templates/base.html`, `app/main.py`
- **action**: Create competitor service and page with discover + manual add + tracking table
- **verify**: Click "Discover Competitors" → see related channels. Manually add a channel → appears as competitor.
- **done**: true

### Task 2: Keyword scoring engine + scored keywords UI
- **files**: `app/services/scoring.py`, `app/routers/trends.py`, `app/templates/trends.html`
- **action**: Create scoring service and update trends page with score button + sorted table
- **verify**: Click "Score Keywords" → keywords sorted by opportunity score
- **done**: true

## Boundaries
- **DO NOT CHANGE:** `.bolt/` files, `app/database.py`, `app/services/analytics.py`, `app/services/trends.py`
- **OUT OF SCOPE:** Metadata generation, niche reports, suggested next video

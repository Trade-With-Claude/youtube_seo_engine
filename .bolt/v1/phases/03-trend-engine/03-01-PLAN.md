# Phase 3: Trend Engine — Plan

## Acceptance Criteria

**AC1:** Given a channel with fetched videos, when I click "Extract Keywords", then keywords are extracted from video titles/tags/descriptions and saved to the keywords table.

**AC2:** Given a search term, when I enter it in the trend search, then I see YouTube autocomplete suggestions and Google Trends data (interest over time via trendspy) with graceful fallback if Trends is blocked.

**AC3:** Given keywords have been tracked over multiple snapshots, when I view the trends page, then I see which keywords are rising, falling, or stable based on autocomplete position tracking.

## Tasks

### Task 1: Keyword extraction + autocomplete scraping
- **files**: `app/services/autocomplete.py`, `app/services/keywords.py`, `app/routers/trends.py`, `app/templates/trends.html`, `app/templates/base.html` (add nav link), `app/main.py`, `requirements.txt`
- **action**: Create keyword extraction service (parse titles, tags, descriptions from stored videos into keywords table). Create autocomplete service hitting YouTube suggest endpoint with delays. Create trends page with: keyword extraction button per channel, search box for autocomplete lookup. Store autocomplete results with timestamps for tracking.
- **verify**: Click "Extract Keywords" → see keywords from your channel's videos. Search "adhd focus music" → see YouTube autocomplete suggestions.
- **done**: false

### Task 2: Google Trends via trendspy + trend tracking UI
- **files**: `app/services/trends.py`, `app/routers/trends.py` (extend), `app/templates/trends.html` (extend), `app/models.py` (add AutocompleteSnapshot model), `requirements.txt`
- **action**: Add `trendspy` dep. Create trends service: `get_interest_over_time(keyword)` with try/except fallback. Add autocomplete snapshot model (keyword, position, timestamp). Create UI showing: interest over time data, rising/falling indicators based on position changes across snapshots, related queries from trendspy.
- **verify**: Search a keyword → see Google Trends interest data (or graceful "Trends unavailable" fallback). After multiple snapshot saves, see rising/falling indicators.
- **done**: false

## Boundaries
- **DO NOT CHANGE:** `.bolt/` files, `app/database.py`, `app/services/analytics.py`, `app/routers/auth.py`
- **OUT OF SCOPE:** Competitor discovery, keyword scoring formula, metadata generation

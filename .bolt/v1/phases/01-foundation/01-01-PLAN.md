# Phase 1: Foundation — Plan

## Acceptance Criteria

**AC1:** Given the app is started, when I visit `http://localhost:8000`, then I see a dashboard with a channel URL input form styled with Tailwind.

**AC2:** Given I paste a YouTube channel URL and submit, when the form posts, then the channel is parsed (extract channel ID/handle) and saved to the `channels` table in SQLite.

**AC3:** Given the database is initialized, when I inspect it, then all 7 tables exist (channels, videos, keywords, keyword_scores, competitors, reports, metadata_templates).

## Tasks

### Task 1: App skeleton + database
- **files**: `app/main.py`, `app/config.py`, `app/database.py`, `app/models.py`, `requirements.txt`, `.env.example`, `.gitignore`
- **action**: Create FastAPI app with Pydantic BaseSettings (.env loading), SQLModel engine with WAL mode, all 7 table models with relationships, requirements.txt with dependencies
- **verify**: `pip install -r requirements.txt && python -c "from app.database import init_db; init_db()"` creates the SQLite DB with all tables
- **done**: false

### Task 2: Dashboard + channel form
- **files**: `app/routers/dashboard.py`, `app/templates/base.html`, `app/templates/dashboard.html`, `app/templates/components/channel_form.html`, `app/static/`
- **action**: Create Jinja2 base layout (Tailwind CDN + HTMX CDN), dashboard page with channel URL input form, POST endpoint that parses YouTube URL (handles @handle, /channel/ID, /c/name formats), saves to DB, redirects to dashboard showing the saved channel
- **verify**: Start app with `uvicorn app.main:app --reload`, visit localhost:8000, paste a URL, see it saved and displayed
- **done**: false

### Task 3: OAuth setup guide page
- **files**: `app/templates/setup.html`, `app/routers/dashboard.py` (add route)
- **action**: Create a `/setup` page with step-by-step Google Cloud Console instructions. Static content, nicely formatted with Tailwind.
- **verify**: Visit `localhost:8000/setup`, see clear setup instructions
- **done**: false

## Boundaries
- **DO NOT CHANGE:** `.bolt/` files
- **OUT OF SCOPE:** Actual YouTube API calls (Phase 2), trend detection, scoring, metadata generation

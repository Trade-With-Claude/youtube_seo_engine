# Phase 5: Metadata & Reports — Plan

## Acceptance Criteria

**AC1:** Given I'm on the report page, when I click "Generate Niche Report", then I see a full report combining: channel stats, top traffic keywords, best opportunities, competitor summary, and content strategy.

**AC2:** Given the niche report is generated, when I look at "Suggested Next Videos", then I see 3-5 concrete video ideas ranked by opportunity, each with a suggested title and why it would work.

## Tasks

### Task 1: Niche report service + page
- **files**: `app/services/reports.py`, `app/routers/reports.py`, `app/templates/report.html`, `app/templates/base.html`, `app/main.py`
- **action**: Create a report service that pulls together all data sources into one niche analysis: channel overview (subs, views, top videos), keyword landscape (top traffic keywords, best opportunities, gaps), competitor positioning, and content strategy summary. Create a dedicated `/report` page to display it.
- **verify**: Visit `/report` → see a full niche report with real data from all sources
- **done**: true

### Task 2: Suggested next videos
- **files**: `app/services/reports.py`, `app/templates/report.html`
- **action**: Add a "Suggested Next Videos" section to the report. Combines top opportunity keywords + traffic winners + patterns from best-performing videos to suggest 3-5 concrete video ideas, each with a title, target keywords, and reasoning.
- **verify**: Report page shows 3-5 video suggestions with titles and reasoning
- **done**: true

## Boundaries
- **DO NOT CHANGE:** `app/services/scoring.py`, `app/services/competitors.py`, `app/services/metadata.py`, `app/database.py`
- **OUT OF SCOPE:** JSON/PDF export, AI-generated descriptions

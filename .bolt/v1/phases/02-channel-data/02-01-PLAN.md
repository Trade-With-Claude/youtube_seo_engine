# Phase 2: Channel Data — Plan

## Acceptance Criteria

**AC1:** Given a channel URL is submitted, when the app processes it, then the channel's real name, subscriber count, video count, and description are fetched from YouTube Data API and displayed on the dashboard.

**AC2:** Given a channel is added, when I click "Fetch Videos", then the channel's recent videos (title, views, likes, tags, published date) are fetched and displayed in a table.

**AC3:** Given I click "Connect YouTube Analytics", when I complete the OAuth flow, then the dashboard shows my top search terms, traffic sources, and revenue data from the Analytics API.

## Tasks

### Task 1: YouTube Data API service + channel resolution
- **files**: `app/services/youtube_api.py`, `app/routers/dashboard.py`, `app/templates/dashboard.html`, `requirements.txt`
- **action**: Add `google-api-python-client` + `google-auth` deps. Create youtube_api service with: `resolve_channel(handle_or_id)` using `channels.list(forHandle=...)`, `fetch_videos(channel_id)` using `playlistItems.list` + `videos.list` (avoids 100-unit search.list). On channel add, auto-resolve to real data (name, subs, video count). Update dashboard to show real stats + video table.
- **verify**: Add your real channel URL → see real name, subscriber count, video list with views/tags
- **done**: false

### Task 2: YouTube Analytics API OAuth flow + data
- **files**: `app/services/analytics.py`, `app/routers/auth.py`, `app/config.py`, `app/models.py` (add OAuthToken model), `app/templates/dashboard.html`, `app/main.py`
- **action**: Add `google-auth-oauthlib` dep. Create OAuth flow: `/auth/start` → Google consent → `/auth/callback` → store refresh token in DB. Create analytics service with: `get_top_search_terms()`, `get_traffic_sources()`, `get_revenue()`. Add "Connect Analytics" button to dashboard. Show analytics data when connected.
- **verify**: Click "Connect YouTube Analytics" → complete Google login → see search terms and traffic data on dashboard
- **done**: false

## Boundaries
- **DO NOT CHANGE:** `.bolt/` files, `app/database.py`
- **OUT OF SCOPE:** Trend detection, competitor discovery, keyword scoring, metadata generation

# Phase 2: Smart Scoring — Plan

## Acceptance Criteria

### AC1: Channel-relative keyword difficulty is enhanced
- Given a channel with scored keywords
- When viewing keyword scores
- Then scores include a `difficulty` label (Easy/Medium/Hard) based on channel size ratio

### AC2: Video SEO score exists
- Given a video with title, description, and tags
- When the SEO scoring service runs
- Then the video gets a 0-100 score with individual breakdowns (title, description, tags) stored in `seo_scores` table

### AC3: Actionable recommendations are shown
- Given a video with an SEO score
- When viewing the SEO scores page
- Then each video shows specific fix-it tips (e.g., "title too short", "add keyword X", "description needs more text")

## Tasks

### Task 1: SEO scoring service + enhanced keyword difficulty
- **files:** `app/services/seo_scoring.py` (new), `app/services/scoring.py`
- **action:** Create `seo_scoring.py` with `score_video_seo(session, video_id)` that grades title (length, keyword presence, power words), description (length, keyword density, links), and tags (count, relevance) on 0-100 scale. Generates JSON recommendations list. Add difficulty label to `scoring.py`'s `get_scored_keywords` output (Easy/Medium/Hard based on competition_component thresholds).
- **verify:** `python -c "from app.services.seo_scoring import score_video_seo, score_all_videos; print('OK')"`
- **done:** true

### Task 2: SEO scores router + UI
- **files:** `app/routers/seo.py` (new), `app/main.py`, `app/templates/seo.html` (new), `app/templates/base.html`
- **action:** Create SEO router with GET `/seo` (show all video scores) and POST `/seo/score` (trigger scoring). Template shows each video with its overall score (color-coded), breakdown bars for title/description/tags, and expandable recommendations list. Add nav link in base.html. Register router in main.py.
- **verify:** Start app, navigate to `/seo`, trigger scoring, see scores and recommendations.
- **done:** true

## Boundaries
- **DO NOT CHANGE:** `app/services/youtube_api.py`, `app/services/vph.py`, OAuth flow, existing scoring formula logic (only add difficulty label to output)
- **OUT OF SCOPE:** AI-powered recommendations, auto-fix capabilities, keyword suggestions for missing keywords

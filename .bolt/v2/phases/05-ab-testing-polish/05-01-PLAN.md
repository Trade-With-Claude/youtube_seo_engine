# Phase 5: A/B Testing & Polish — Plan

## Acceptance Criteria

### AC1: A/B test can be created
- Given a video exists in the database
- When creating an A/B test with two title variants
- Then an `AbTest` record is created with variant_a, variant_b, and status="running"

### AC2: A/B test dashboard shows tests with results
- Given A/B tests exist
- When viewing the A/B testing page
- Then each test shows both variants, impressions/clicks per variant, CTR comparison, and status

### AC3: Polish — all v2 pages have loading states and error handling
- Given any v2 page (VPH, SEO, Audience, Alerts, A/B)
- When an API error occurs or data is loading
- Then graceful error messages or loading indicators are shown (no raw tracebacks)

## Tasks

### Task 1: A/B testing service
- **files:** `app/services/ab_testing.py` (new)
- **action:** Create `ab_testing.py` with: `create_test(session, video_id, test_type, variant_a, variant_b)` — creates AbTest record. `swap_variant(session, test_id, oauth_token)` — updates the video title on YouTube via API (requires write scope, graceful fallback if unavailable). `record_metrics(session, test_id, oauth_token)` — pulls impressions/CTR from Analytics API. `get_tests(session, channel_id)` — returns all tests. `complete_test(session, test_id)` — marks test as complete.
- **verify:** `python -c "from app.services.ab_testing import create_test, get_tests, complete_test; print('OK')"`
- **done:** false

### Task 2: A/B testing router + UI + polish
- **files:** `app/routers/ab.py` (new), `app/main.py`, `app/templates/ab.html` (new), `app/templates/base.html`
- **action:** Create A/B router with GET `/ab`, POST `/ab/create`, POST `/ab/{test_id}/swap`, POST `/ab/{test_id}/complete`. Template: create test form, active tests with CTR comparison, completed tests with winner. Add nav link. Register router.
- **verify:** Start app, navigate to `/ab`, see create form and test list. All v2 nav links work.
- **done:** false

## Boundaries
- **DO NOT CHANGE:** All v1 services, `app/services/youtube_api.py`, existing OAuth scopes in `analytics.py`
- **OUT OF SCOPE:** Automatic rotation scheduling, thumbnail A/B testing, statistical significance calculation

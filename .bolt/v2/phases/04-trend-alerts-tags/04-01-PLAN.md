# Phase 4: Trend Alerts & Tags — Plan

## Acceptance Criteria

### AC1: Trend velocity detection works
- Given autocomplete snapshots tracked over time
- When the trend detection service runs
- Then keywords with rising/falling velocity are flagged as `TrendAlert` records

### AC2: Trend alerts UI shows rising/falling keywords
- Given trend alerts exist in the database
- When viewing the alerts page
- Then a list shows keyword, alert type (rising/falling/spike), velocity, and created date

### AC3: Competitor tag analysis works
- Given competitors with fetched videos
- When viewing the tag analysis section
- Then it shows most-used tags per competitor, tag overlap with your channel, and tag gaps

## Tasks

### Task 1: Trend velocity service + competitor tag analysis service
- **files:** `app/services/trend_alerts.py` (new), `app/services/tag_analysis.py` (new)
- **action:** Create `trend_alerts.py` with `detect_trends(session)` — compares autocomplete snapshots across time periods, calculates velocity (position change rate), creates TrendAlert records for keywords rising/falling above threshold. Create `tag_analysis.py` with `analyze_competitor_tags(session, channel_id)` — extracts tags from all competitor videos, counts frequency, compares with your channel's tags to find overlaps and gaps.
- **verify:** `python -c "from app.services.trend_alerts import detect_trends; from app.services.tag_analysis import analyze_competitor_tags; print('OK')"`
- **done:** false

### Task 2: Trend alerts + tag analysis router + UI
- **files:** `app/routers/alerts.py` (new), `app/main.py`, `app/templates/alerts.html` (new), `app/templates/base.html`
- **action:** Create alerts router with GET `/alerts` showing two sections: (1) Trend alerts table with keyword, type badge (rising/falling/spike), velocity value, and created date. Mark-as-seen button. (2) Tag analysis section with competitor tag frequency table, your tag overlap percentage, and "missing tags" list. Add nav link and register router.
- **verify:** Start app, navigate to `/alerts`, see trend alerts and tag analysis sections (or empty states).
- **done:** false

## Boundaries
- **DO NOT CHANGE:** `app/services/autocomplete.py`, `app/services/competitors.py`, `app/services/youtube_api.py`, existing trend/competitor templates
- **OUT OF SCOPE:** Push/email notifications, automated tag suggestions applied to videos, scheduled trend detection

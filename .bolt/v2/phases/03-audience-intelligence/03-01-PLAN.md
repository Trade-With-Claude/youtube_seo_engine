# Phase 3: Audience Intelligence — Plan

## Acceptance Criteria

### AC1: Best time to publish data is available
- Given a channel with OAuth connected
- When the audience activity service runs
- Then a day/hour activity matrix is returned with relative viewer activity levels

### AC2: Heat map UI shows optimal publish windows
- Given audience activity data exists
- When viewing the audience intelligence page
- Then a visual heat map displays activity by day (rows) and hour (columns), color-coded by intensity

### AC3: Subscriber source report works
- Given a channel with OAuth connected
- When viewing the audience intelligence page
- Then a table shows which videos/traffic sources drive the most subscriptions

## Tasks

### Task 1: Audience analytics service
- **files:** `app/services/audience.py` (new)
- **action:** Create `audience.py` with: (1) `get_audience_activity(oauth_token)` — queries YouTube Analytics for viewer activity by day-of-week and hour, returns 7x24 matrix. (2) `get_subscriber_sources(oauth_token)` — queries YouTube Analytics for subscriptions by traffic source and by video, returns ranked list. Uses existing `get_analytics_service()` and `get_credentials_from_token()` from analytics.py.
- **verify:** `python -c "from app.services.audience import get_audience_activity, get_subscriber_sources; print('OK')"`
- **done:** false

### Task 2: Audience intelligence router + UI
- **files:** `app/routers/audience.py` (new), `app/main.py`, `app/templates/audience.html` (new), `app/templates/base.html`
- **action:** Create audience router with GET `/audience` (show heat map + subscriber sources). Template includes: (1) CSS grid heat map — 7 rows (Mon-Sun) x 24 cols (hours), cells colored green intensity by activity level. (2) Best 3 publish windows highlighted. (3) Subscriber sources table with video title, source type, and subscriber count. Add nav link. Register router.
- **verify:** Start app, navigate to `/audience`, see heat map and subscriber table (or graceful "Connect OAuth first" message).
- **done:** false

## Boundaries
- **DO NOT CHANGE:** `app/services/analytics.py` (import from it, don't modify), `app/services/youtube_api.py`, VPH/SEO scoring code
- **OUT OF SCOPE:** Push notifications, scheduled publish automation, historical trend of audience activity over time
